# Blaze Bowling

## About the Project

Blaze Bowling is a game project created to improve my game development skills and expand my portfolio.

The project helped me explore new Unity tools and apply them in practice while improving the game's visual presentation and player experience.

## What I Learned

While developing Blaze Bowling, I used several features for the first time, including DOTween animations, sound effects, and raycasts in code.

I also improved the visual design of the game and created moving platforms using Vector3 and Transform.position.

## Technical Features

- Used DOTween to create animations
- Added sound effects
- Implemented raycasts in C#
- Improved the visual design of the game
- Created moving platforms using Vector3 and Transform.position

## Technologies

- Unity
- C#
- DOTween
- Raycasts
- Vector3
- Transform
